# v1.4.0 主要优化：
# 1) 事件分发无锁化：原先每条弹幕分发都要对 handler map 加一次 RWMutex（pprof 显示其占
#    HandleActionSignal 总开销近四成）；改为注册时写时复制生成 handler 列表的不可变快照，
#    热路径通过 atomic.Pointer 免锁读取。单 handler 仍同步调用、多 handler 仍并发派发。
#    BenchmarkCallEvent_Single 由 ~16.3ns 降至 ~8.8ns（约 -46%）。
# 2) 补齐 notify 信号对象池：handleNotifySignal 此前未使用已声明的 notifySignalPool 等
#    对象池、每条 notify 都新建 protobuf 消息，现已与 action/state 信号一致池化，降低
#    notify 路径的分配与 GC 压力。
# 3) 徽章解析去闭包：newUserInfo 解析守护徽章时改用按字段直接取值，避免 Visit 闭包在每条
#    带徽章弹幕上的堆分配。
#
# 关于池化内层消息安全性的验证：google.golang.org/protobuf 在 Unmarshal 时会对 string 字段
# 做拷贝（不零拷贝引用输入缓冲），因此 putProto(Reset) 仅清空消息自身的拷贝字段，已派发的
# 弹幕 DanmuMessage 持有的是独立拷贝，池化安全（见 alias_test.go: TestProtoStringAliasing）。
